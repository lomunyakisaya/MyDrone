LDOS

Lomunyak Drone Operating System

LDOS is a modular drone operating system focused on autonomous flight, real-time telemetry, mission planning, remote control, and onboard intelligence.

Built around embedded systems and wireless communication, LDOS aims to provide a flexible platform for developing intelligent autonomous drones.

Core Features

- Flight stabilization and motor control
- GPS navigation and sensor fusion
- Real-time telemetry
- Ground station and mission planning
- Remote control and monitoring
- Camera streaming and computer vision
- Wi-Fi, WebSockets and MQTT communication

Technology Stack

- C/C++
- ESP8266 / ESP32
- Arduino Framework
- JavaScript, HTML and CSS
- MQTT and WebSockets

Vision

To build a modular autonomous aerial platform combining flight control, communication, navigation, and intelligent decision-making.
